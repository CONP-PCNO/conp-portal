On an Alliance (DRAC) cluster

Docker isn't available on Alliance clusters; Apptainer runs the same container. Set up once on a login node (it needs internet access, which compute nodes on some clusters don't have), then run the tool in a job.

1. Once, on a login node

{{ codebox([ 'module load python apptainer', 'virtualenv --no-download ~/boutiques-env', 'source ~/boutiques-env/bin/activate', 'pip install --no-index --upgrade pip', 'pip install boutiques # from PyPI: no Alliance wheel for it', 'bosh pull ' ~ pipeline.id, 'bosh example ' ~ pipeline.id ~ ' > invocation.json # fill in your inputs', 'export APPTAINER_CACHEDIR=/tmp/$USER APPTAINER_TMPDIR=/tmp/$USER', 'mkdir -p $APPTAINER_CACHEDIR', 'apptainer build ' ~ page.container.sif ~ ' ' ~ page.container.pull, ]) }}

2. In your job script (sbatch) or an interactive job (salloc)

{{ codebox([ 'module load python apptainer', 'source ~/boutiques-env/bin/activate', 'bosh exec launch -s ' ~ pipeline.id ~ ' invocation.json --imagepath ' ~ page.container.sif, ]) }}

Boutiques mounts the current directory and the input files named in invocation.json; add -v /project:/project (or /scratch) for anything else. Ask the scheduler for the resources under Details. Apptainer · Python virtual environments · Running jobs on Alliance clusters
