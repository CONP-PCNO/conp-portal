On an Alliance (DRAC) cluster

Docker isn't available on Alliance clusters, but Apptainer can run the same container. Work in a folder you can write to: the commands below use $SCRATCH/conp as an example.

1. Once, on a login node

{{ codebox([ 'module load python', 'virtualenv --no-download ~/boutiques-env', 'source ~/boutiques-env/bin/activate', 'pip install --no-index --upgrade pip', 'pip install boutiques # from PyPI: no Alliance wheel for it', 'mkdir -p $SCRATCH/conp && cd $SCRATCH/conp', 'bosh pull ' ~ pipeline.id, 'bosh example ' ~ pipeline.id ~ ' > invocation.json # fill in your inputs', ]) }} {{ sources([ ('Alliance: Python virtual environments', 'https://docs.alliancecan.ca/wiki/Python#Creating_and_using_a_virtual_environment'), ('Alliance: available Python wheels', 'https://docs.alliancecan.ca/wiki/Available_Python_wheels'), ('Boutiques tutorial', 'https://nbviewer.jupyter.org/github/boutiques/tutorial/blob/master/notebooks/boutiques-tutorial.ipynb'), ]) }}

2. Once, build the image on a login node (it needs internet access, which compute nodes on some clusters, Rorqual among them, don't have). Apptainer's working files go on scratch, because /tmp on a login node uses memory.

{{ codebox([ 'module load apptainer', 'cd $SCRATCH/conp', 'export APPTAINER_CACHEDIR=$SCRATCH/apptainer/cache APPTAINER_TMPDIR=$SCRATCH/apptainer/tmp', 'mkdir -p $APPTAINER_CACHEDIR $APPTAINER_TMPDIR', 'apptainer build ' ~ page.container.sif ~ ' ' ~ page.container.pull, ]) }} {{ sources([ ('Alliance: building an Apptainer image', 'https://docs.alliancecan.ca/wiki/Apptainer#Building_an_SIF_image'), ('Alliance: changing Apptainer\'s directories', 'https://docs.alliancecan.ca/wiki/Apptainer#Changing_Apptainer%27s_default_directories'), ('Alliance: Rorqual (no internet on compute nodes)', 'https://docs.alliancecan.ca/wiki/Rorqual/en'), ('Apptainer: build environment', 'https://apptainer.org/docs/user/latest/build_env.html'), ]) }}

3. In your job script (sbatch) or an interactive job (salloc)

{{ codebox([ 'module load python apptainer', 'source ~/boutiques-env/bin/activate', 'cd $SCRATCH/conp', 'bosh exec launch -s ' ~ pipeline.id ~ ' invocation.json --imagepath ' ~ page.container.sif, ]) }}
A complete job script

Save as run.sh, set the account and the resources for your data, then sbatch run.sh.

{{ codebox([ '#!/bin/bash', '#SBATCH --account=def-yourpi # your group\'s allocation', '#SBATCH --time=' ~ ('12:00:00' if page.runs_long else '01:00:00') ~ ' # hh:mm:ss', '#SBATCH --cpus-per-task=' ~ (page.cpus or 1), '#SBATCH --mem=' ~ (page.mem_gb or 4) ~ 'G', 'module load python apptainer', 'source ~/boutiques-env/bin/activate', 'cd $SCRATCH/conp', 'bosh exec launch -s ' ~ pipeline.id ~ ' invocation.json --imagepath ' ~ page.container.sif, ]) }}
{{ sources([ ('Alliance: running jobs', 'https://docs.alliancecan.ca/wiki/Running_jobs'), ('Alliance: Apptainer', 'https://docs.alliancecan.ca/wiki/Apptainer'), ('Boutiques tutorial', 'https://nbviewer.jupyter.org/github/boutiques/tutorial/blob/master/notebooks/boutiques-tutorial.ipynb'), ]) }}

Boutiques mounts the current directory and the input files named in invocation.json; add -v /project:/project for anything else. Scratch is for temporary files (older ones are purged), so keep images you reuse in your group's project space (under /project; linked from your home directory, e.g. ~/links/projects on Rorqual). Large images (FreeSurfer, fMRIPrep) take a while to build; if a build is stopped for memory, ask Alliance support. Size the job for your data:{% if page.runs_long %} a full recon-all run usually takes hours per subject;{% endif %} the estimate under Details is the descriptor authors' and can be far off.
